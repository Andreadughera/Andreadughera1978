# DollarSpot Sentinel v5.2 - Integrazione MeteoProvider nel modello rischio

## Obiettivo

Collegare il calcolo rischio ufficiale a una fonte meteo resiliente:

```text
Open-Meteo live -> MeteoCache -> errore controllato
```

Il modulo `apps-script/MeteoProvider_v5_2.gs` espone la funzione:

```javascript
fetchMeteoV52({
  campoId: campoId,
  nomeCampo: nomeCampo,
  lat: lat,
  lon: lon
});
```

## Differenza rispetto a `fetchMeteo(lat, lon)`

La vecchia funzione:

```javascript
var meteo = fetchMeteo(lat, lon);
```

dipende direttamente dalle API live.

La nuova funzione:

```javascript
var meteo = fetchMeteoV52({
  campoId: campoId,
  nomeCampo: nomeCampo,
  lat: lat,
  lon: lon
});
```

fa tre cose:

1. prova Open-Meteo live;
2. se funziona, aggiorna `MeteoCache`;
3. se fallisce, prova a ricostruire i dati da `MeteoCache`.

## Modifica consigliata in `eseguiAlertGiornaliero`

Prima:

```javascript
var meteo = fetchMeteo(lat, lon);
if (!meteo) { Logger.log("  Errore meteo"); continue; }
```

Dopo:

```javascript
var campoId = r[campoIdIndex] || nomeCampo.replace(/\s+/g, '-').toLowerCase();
var meteo = fetchMeteoV52({
  campoId: campoId,
  nomeCampo: nomeCampo,
  lat: lat,
  lon: lon
});

Logger.log("  " + getMeteoQualityLabelV52(meteo));

if (!shouldSendAlertWithMeteoV52(meteo)) {
  Logger.log("  Meteo non affidabile: skip alert automatico");
  continue;
}
```

## Modifica LWD

Prima nel modello:

```javascript
var lwd = stimaLWD(hourly, dateStr);
```

Dopo:

```javascript
var lwd = getLwdOreV52(meteo, hourly, dateStr);
```

Questo permette di usare:

- LWD oraria se disponibile;
- LWD salvata in `MeteoCache` se il dato live non c'e.

## Modifica temperatura suolo

Prima:

```javascript
var tSuolo = getTSuoloGiorno(d, meteo.archH);
```

Dopo:

```javascript
var tSuolo = getTSuoloGiornoV52(meteo, meteo.archH, d);
```

## Email e trasparenza dato

Aggiungere nella mail e nel riepilogo agronomo:

```javascript
getMeteoQualityLabelV52(meteo)
```

Esempi:

```text
meteo: live (open-meteo) - Dati live aggiornati e salvati in MeteoCache
meteo: cache_oggi (MeteoCache) - Fallback da MeteoCache dopo errore live
meteo: cache_recente (MeteoCache) - Fallback da MeteoCache dopo errore live
```

## Policy consigliata per alert

| Qualita dato | Alert superintendent | Riepilogo agronomo |
| --- | --- | --- |
| `live` | si | si |
| `cache_oggi` | si, con nota | si |
| `cache_recente` | opzionale, prudente | si, con avviso |
| `errore` | no | si, errore |
